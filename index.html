📝 Random Line API

Retrieves a random line from a Pastebin raw link using '#' as a line separator.

API Endpoint:
/api/random-line?url=PASTEBIN_RAW_URL
StreamElements Usage:
${customapi.YOUR_VERCEL_URL/api/random-line?url=https://pastebin.com/raw/XXXXXX}
Pastebin Format Example:
First line # Second line # Third line # Fourth line

Each API call returns a different random line from your Pastebin.
